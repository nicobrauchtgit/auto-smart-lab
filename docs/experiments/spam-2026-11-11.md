Observed quirks:

- **Research becomes a modeling sweep.** The agent wrote a roughly 100-line
  `analysis/probe.py` evaluating six text representations with five-fold
  logistic-regression validation over all 16,662 training messages: word
  unigrams, word unigrams/bigrams, character n-grams, punctuation tokens, and
  two metadata combinations. That is up to 30 fits before solve, with none
  eligible as harness promotion evidence. The code uses sublinear term counts,
  not binary TF-IDF. This is an early example of extra complexity; no final
  approach or validated result exists yet.
- **Dense conversion creates memory pressure.** The metadata variants call
  `Xtr.toarray()` and `np.hstack` on text features with caps of 100,000 and
  200,000 columns. The research process reached roughly 8 GiB RSS, while
  available host RAM fell to 5.8 GiB and swap use rose to about 1.7 GiB. It was
  actively consuming CPU; the resource guard had not triggered. No restart
  was warranted at this observation. The current prompt already requests
  cheap sampled fits and one job; the configured `n_jobs=1` intent does not
  bound dense-matrix allocations or native-library threads.
- **Exploratory validation leaks preprocessing across folds.**
  `vec.fit_transform(docs)` occurs before cross-validation, and metadata is
  standardized over all rows before splitting. Any resulting exploratory
  score must be treated separately from honest fold-local preprocessing and
  authoritative harness measurements.
- **Small tool mistakes add controller overhead.** The controller first
  supplied dataset filenames as trusted artifact IDs (rejected), then omitted
  required `rationale` on a retry (schema error), before starting research.
  Research's first probe run failed with an `UnboundLocalError` for
  `Xtr, Xte = Xd[tr], Xte[te]`; its first edit failed to match the source, then
  it corrected the line itself with `sed`. These were self-repaired model
  mistakes, not operator interventions.
- **A successful shell exit can hide a failed analysis.** The probe command
  piped Python into `tail` without `pipefail`. The traceback was visible to
  the agent, but the completed bash observation at 23:28:00 UTC was marked
  `DEFAULT` rather than `ERROR`, because `tail` exited successfully. Report
  artifact validation remains necessary; tool success alone is weak evidence.

Fix candidates after this batch: account for research fits/time/memory alongside
solve trials; preserve sparse representations when adding features; require
fold-local learned preprocessing in evidence checks; make trusted-artifact
identities and tool validation failures clearer in controller telemetry. These
are proposals, not changes injected into the running experiment.
