Task {{taskId}} is multiclass classification. The entrypoint is `solutions/tasks/{{taskId}}.py`; create it if it does not exist. It exposes `build_pipeline()` returning a fresh, unfitted object with `fit(X, y)` and `predict(X)`. The harness supplies a frame with `id` and `input` columns. Each `input` is `{"archive": <absolute path of a zip archive>, "member": <member name>}`; your code reads the raw sample bytes from that archive member. Test member names carry no label, so the id, member name and ordering must never be used as features. The harness calls `fit(training_frame, labels)` and `predict(validation_frame)`. Labels are website class-name strings. Predict returns one training class name per input row, in input order. The primary metric is sklearn balanced_accuracy_score (macro recall); measurements also include accuracy, per-class recall and top confusion pairs. Binary ranking, threshold and calibration diagnostics are unavailable. Terminal refit fits all training rows and predicts test rows. Delivery is one `id;class_name` line per test ID, without a header.
