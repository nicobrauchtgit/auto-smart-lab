Task {{taskId}} is multiclass classification. Declare an unfitted pipeline in `solutions/tasks/{{taskId}}.py` using the registered pipeline factory. The harness supplies a frame with `id` and opaque `input` descriptors. It calls `fit(training_frame, labels)` and `predict(validation_frame)`. Labels are website class-name strings. Predict returns one training class name per input row, in input order. The primary metric is sklearn balanced_accuracy_score (macro recall); measurements also include accuracy, per-class recall and top confusion pairs. Binary ranking, threshold and calibration diagnostics are unavailable. Terminal refit fits all training rows and predicts test rows. Delivery is one `id;class_name` line per test ID, without a header.
