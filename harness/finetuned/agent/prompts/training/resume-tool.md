Resume an existing interrupted or intentionally paused experiment by id. Inspect experiment_status and output first. Recovery keeps the experiment ID, original budget unit, exact committed source (including champion), dataset/dependency identity, persisted folds, seeds and configuration journal. It consumes no new experiment unit. Completed configurations and single-trial folds with atomic prediction checkpoints are retained; an interrupted opaque fit cannot be checkpointed. A search configuration lost during a fit is marked failed and uses its original configuration slot; it is never silently retried. Single-trial incomplete folds are fitted again using their original seeds.

On restart the harness reattaches a verified live worker without launching another, or attempts at most two recoveries of unexpected worker death. Quiet output is never proof of death. A live orphan process group blocks recovery. Intentional stop, service close and runtime cost pauses require this explicit tool; completed/failed experiments, exhausted hard caps and incompatible/corrupt state cannot resume. Runtime pauses require acceptEstimatedSeconds covering the reported projected total; this acknowledgement changes only the cost acceptance, never the original hard cap, search or experiment budget. Errors explain which original inputs to restore. Inspect recovery events and retained measurements before proceeding.
