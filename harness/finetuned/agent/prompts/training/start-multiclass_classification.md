Start a harness-owned multiclass classification trial with string class labels. The pipeline factory returns an unfitted object with fit/predict. The request contains schemaVersion 2, hypothesis, pipeline:{module,factory,parameters?,estimatorParams?}, cv and scope:{kind:"promotion"} or a pilot scope. Source must be committed. Seeds, folds, fits, predictions and measurements belong to the harness. Predict returns one of the training class names per input row. The primary metric is balanced accuracy (macro recall). Optional search:{space,sampler,maxConfigs,pruning} supports factory.* parameters and estimator set_params names. A completed search winner measured on all shared folds counts as a trial. Paired fold differences compare champions.
